# 도면 검토 기준서

## 입력
- 도면: inputs/ 폴더의 PDF 또는 DXF
- 체크리스트: inputs/ 폴더의 PDF 또는 XLSX (없으면 기본 항목 사용)

## 검토 절차
1. scripts/extract.py 를 실행해 도면의 텍스트·치수·좌표를 뽑는다.
2. 체크리스트를 읽어 점검 항목 목록을 만든다.
3. 각 항목을 도면 데이터와 대조해 통과/확인/오류로 판정한다.
4. 항목마다 도면 내 위치(page, x, y)를 찾아 기록한다.
5. scripts/mark.py 로 색상 마킹된 결과 PDF를 만든다.

## 판정·색상 규칙 (반드시 준수)
- 파란색(blue): 일반 확인사항·정상 항목
- 빨간색(red): 오류·수정필요·중점 체크 항목

## 출력 형식 (항목마다 JSON 한 줄)
{ "category": "법규|QC", "item": "점검내용",
  "result": "pass|check|error", "color": "blue|red",
  "page": 1, "x": 0, "y": 0, "comment": "근거/조치" }

## 기본 점검 항목(체크리스트가 없을 때)
- 법규: 피난거리, 복도/계단 폭, 방화구획, 비상구, 주차대수
- QC: 도면 누락, 치수 불일치, 범례/축척 표기, 도면번호 연속성
